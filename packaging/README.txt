TorrentClient для Windows

1. Распакуйте ZIP целиком в отдельную папку.
2. Запустите TorrentClient.exe двойным щелчком.
3. Добавьте .torrent или magnet и выберите папку загрузки.

Все DLL из архива должны оставаться рядом с TorrentClient.exe.
Установка компилятора, CMake или Node.js для запуска не требуется.

Настройки, список загрузок и журнал находятся в:
%LOCALAPPDATA%\TorrentClient
Папка загрузки по умолчанию:
%USERPROFILE%\Downloads\TorrentClient

Для продолжения сохранённых .torrent-загрузок исходные .torrent-файлы должны
оставаться доступны. Проверенные части сохраняются рядом со скачанными файлами.

SHA256SUMS.txt содержит контрольные суммы файлов этой сборки.
BUILD-INFO.txt содержит версию и параметры сборки.
Архив не подписан цифровой подписью.
